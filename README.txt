Burai Fighter Deluxe: Level Select v1.0
Game Boy ROM hack by wavedout | September 25, 2026

This patch adds LEVEL SELECT to the title screen. NEW GAME follows the
original start sequence. LEVEL SELECT lets you choose stages 1-5, starting
lives of 3, 5, 9, or INFINITE, and your starting weapons. Then choose the
original Eagle, Albatross, Ace, or Ultimate difficulty. The game labels
this difficulty page SELECT LEVEL.

CONTROLS
On LEVEL SELECT, Up/Down chooses STAGE, LIVES, or WEAPONS. Right or A
advances a value; Left goes back. Start opens difficulty. B returns to
the previous screen. Returning from difficulty preserves your settings.

WEAPONS AND LIVES
BASE starts with the original gun. LASER, RING, and MISSILE start the
selected weapon at maximum power. FULL LASER, FULL RING, and FULL MISSILE
start all three weapons at maximum power; the named weapon is equipped
first. These are starting loadouts; normal gameplay rules still apply.
Lives are total starting lives. The HUD displays spare lives, so 3 starts
with 2 shown. INFINITE shows 99.

PATCHING
Apply ONE patch to an unmodified Burai Fighter Deluxe (USA, Europe) Game
Boy ROM using a compatible patcher:

  Burai Fighter Deluxe - Level Select.bps  (recommended)
  Burai Fighter Deluxe - Level Select.ips  (compatibility)

BPS verifies the source ROM before patching. Do not apply both patches.
